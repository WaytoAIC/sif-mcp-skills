# Changelog

All notable changes to this repository will be documented in this file.

The format is based on Keep a Changelog and this project follows Semantic Versioning.

## [Unreleased]

- No unreleased changes yet.

## [1.0.1] - 2026-10-12

### Changed

- README and SKILLS symlink examples now run from the repository root instead of using a local absolute path.
- The installer default and the README install command now pin `--ref v1.0.1`.

## [1.0.0] - 2026-04-16

### Added

- Initial public release of the SIF MCP skill bundle
- `sif-mcp-router` for cross-domain routing
- `sif-traffic-diagnosis` for traffic and sales impact analysis
- `sif-keyword-research` for keyword demand and ASIN keyword signal workflows
- `sif-ad-analysis` for ad structure and contribution analysis
- Root usage manual and separate skill invocation guide
- `install.sh` for Codex and OpenClaw installation
